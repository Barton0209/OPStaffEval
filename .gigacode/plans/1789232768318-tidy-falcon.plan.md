# План Security Audit: System_Ocenok (KingiseppApp / OPStaffEval)

## Цель
Провести полный аудит безопасности, архитектуры, БД, фронтенда и соответствия ТЗ/152-ФЗ.

## Методология
- Только операции ЧТЕНИЯ (ни один файл не будет изменён)
- Параллельный запуск 5 специализированных агентов

## Задачи агентов

### Agent 1: Security Backend
- config.py: хардкод секретов, пароли
- security.py: JWT, хеширование, TTL, refresh
- main.py: CORS, security headers, middleware
- deps.py: зависимости, проверка ролей
- api/admin.py, api/field.py: эскалация привилегий, organization_id check
- rate_limit.py: rate limiting на login
- backup_util.py: WAL-режим, корректность бэкапов

### Agent 2: Security Frontend & Transport
- api.ts: хранение токенов, http vs https
- offline.ts: Service Worker, IndexedDB
- ChangePasswordModal.tsx: self-service смена пароля
- ExcelSheet.tsx: XSS через Excel, инъекции
- Vite config, CSP, security headers
- PWA manifest, android:allowBackup

### Agent 3: Database & Migrations
- models.py: PRAGMA foreign_keys, индексы
- db.py: WAL режим, сессии
- alembic/: миграции vs create_all
- scheduler.py: N+1 запросы
- registry.py: _collect N+1
- backup_util.py: checkpoint в WAL

### Agent 4: Architecture & Code Quality
- services/: дублирование логики
- schemas.py: validation
- models.py: datetime.utcnow(), магические строки
- logging_setup.py: print vs logging
- нейминг, кириллица в идентификаторах
- error handling: bare except

### Agent 5: TZ Compliance & Deployment
- docs/TZ_v0.2.md: сверка с ТЗ
- setup.bat, start.bat, stop.bat
- Android: build-android.bat, debug vs release
- .env файлы, test scripts, cloudflared.exe
- Артефакты в рабочей папке

## Формат результата
Отчёт по структуре:
1. Общая характеристика
2. Находки по критичности (P0-P3)
3. Приоритизированные рекомендации
4. Итоговая оценка
