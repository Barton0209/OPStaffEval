# KingiseppApp — Portable MVP (Вариант Г)

Пилот оценки персонала ОП **Кингисепп (ВСМ)**.

**Как скачать и запустить на другом ПК (Кингисепп):** см. **[УСТАНОВКА_КИНГИСЕПП.md](УСТАНОВКА_КИНГИСЕПП.md)**

## Быстрый старт (уже установлено)

```bat
cd …\KingiseppApp
setup.bat
start.bat
```

Локально: http://127.0.0.1:8000

> ⚠️ **ВНИМАНИЕ: Публичные туннели (tunnel.bat, tunnel-lt.bat) УДАЛЕНЫ.**
> Их использование нарушает 152-ФЗ (персональные данные РФ).
> Для удалённого доступа используйте VPN или VPS с HTTPS.

| Кто | Логин | Пароль |
|---|---|---|
| Админ ОП | `ADMIN-OP` | Временный пароль указан в логах при первом запуске |
| Нач. участка | `CHIEF-OP` | Временный пароль указан в логах при первом запуске |
| Мастер/ПР | таб. из Excel | Обычно `K` + цифры (уточняйте у администратора) |

> ⚠️ Временные пароли выдаются при первом запуске и логируются в `logs/app.log`.
> Обязательно смените пароль при первом входе.

## Android-приложение

См. **[ANDROID.md](ANDROID.md)** — Capacitor APK, подключается к тому же серверу.

```bat
build-android.bat
```

или: `cd frontend` → `npm run android` (откроет Android Studio).

В приложении на экране входа вставьте адрес LAN-сервера (например, `http://192.168.1.100:8080`).

## Безопасность (LAN)

- По умолчанию API работает по **HTTP** на порту 8080 (Caddy reverse proxy).
- Для HTTPS с self-signed сертификатом см. **Caddyfile** — раскомментируйте блок `:8443`.
- Для генерации self-signed cert:
  ```bat
  openssl req -x509 -newkey rsa:4096 -keyout caddy.key -out caddy.crt -days 365 -nodes
  ```
