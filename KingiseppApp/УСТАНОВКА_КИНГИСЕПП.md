# Как скачать и запустить в Кингисеппе

Репозиторий: https://github.com/mymyproject/OmiK
Локальные Excel / база / пароли **в GitHub не лежат** — их передаёте отдельно (флешка / архив / внутренний диск).

## Что нужно на ПК в Кингисеппе

1. **Python 3.11+** — https://www.python.org/downloads/
   При установке включить **Add python.exe to PATH**.
2. **Node.js LTS** — https://nodejs.org/
3. Архив Excel (папка `Files`) с вашей стороны:
   - `01_База_1С.xlsx`
   - `02_Пользователи.xlsx`
   - `03_Реестр_закрепления.xlsx`
   - `05_Анкеты.xlsx` (необязательно для старта)

## Шаги

### 1. Скачать код

На GitHub → зелёная кнопка **Code** → **Download ZIP**
или:

```bat
git clone https://github.com/mymyproject/OmiK.git
```

Распаковать, например в `C:\Kingisepp\OmiK`

Структура должна быть такой:

```text
OmiK\
  Files\          ← сюда положить Excel (создайте, если нет)
  KingiseppApp\
    setup.bat
    start.bat
    ...
```

### 2. Excel

Скопировать файлы из вашего архива в:

`OmiK\Files\`

### 3. Установка (один раз)

```bat
cd C:\Kingisepp\OmiK\KingiseppApp
setup.bat
```

Скрипт создаст venv, поставит зависимости и соберёт сайт.

### 4. Запуск каждый день

```bat
cd C:\Kingisepp\OmiK\KingiseppApp
start.bat
```

Открыть в браузере: **http://127.0.0.1:8000**

| Кто | Логин | Пароль |
|---|---|---|
| Админ ОП | `ADMIN-OP` | Временный пароль в `logs/app.log` при первом запуске |
| Нач. участка | `CHIEF-OP` | Временный пароль в `logs/app.log` при первом запуске |
| Мастер / прораб | табельный из Excel | Обычно `K` + цифры табеля (уточняйте у администратора) |

> ⚠️ Временные пароли выдаются при первом запуске и логируются в `logs/app.log`.
> Обязательно смените пароль при первом входе.

### 5. Телефоны мастеров / прорабов

**Вариант А — та же Wi‑Fi / VPN, что ПК с сервером (РЕКОМЕНДУЕТСЯ)**

1. `start.bat` уже запущен
2. `caddy-lan.bat`
3. На телефоне: `http://<IP-этого-ПК>:8080`
   (IP смотрите в окне `caddy-lan.bat`, обычно сеть `10.…`)

> ⚠️ **Публичные туннели (tunnel.bat, tunnel-lt.bat) УДАЛЕНЫ из проекта.**
> Их использование нарушает 152-ФЗ (персональные данные РФ).
> Для удалённого доступа используйте VPN или VPS с HTTPS.

## Обновление кода позже

```bat
cd C:\Kingisepp\OmiK
git pull
cd KingiseppApp
setup.bat
start.bat
```

Excel и папка `data\` (база) при `git pull` **не затираются**, если вы их не коммитили.

## Частые проблемы

| Симптом | Что сделать |
|---|---|
| `Нет venv` | Запустить `setup.bat` |
| Пустой список у мастера | Проверить Excel в `Files\` и импорт в админке |
| С телефона не открывается LAN | Нужна та же сеть |
| 503 | Перезапустить `start.bat` |

## Что не отдавать в общий доступ

- папка `Files\` (персональные данные)
- `KingiseppApp\.env`
- `KingiseppApp\data\kingisepp.db`
- `KingiseppApp\logs\` (содержит временные пароли)
