# System_Ocenok - Project Overview

## Purpose and Value Proposition

System_Ocenok (Оценка - "Evaluation" in Russian) is a comprehensive workforce evaluation and management system designed for the Kingisepp construction project. The system provides a complete platform for managing employee assessments, assignments, tariff grids, and performance evaluations across multiple construction sites and specialized work units.

The system addresses critical needs in construction project management:
- Centralized employee evaluation and rating system
- Automated daily report collection and processing
- Real-time assignment tracking and delegation management
- Multi-level approval workflows for evaluations
- Historical data tracking and reporting capabilities

## Key Features and Capabilities

### Multi-Role Access System
- **Admin Panel**: Full system administration, user management, and configuration
- **Economist Panel**: Tariff grid management, salary calculations, and economic analysis
- **Field Worker Panel**: Daily reporting, assignment viewing, and evaluation submission
- **Registry System**: Employee assignment tracking and delegation management

### Core Functional Modules
- **Assignment Management**: Create, assign, and track work assignments across construction sites
- **Daily Reporting**: Automated daily report collection and processing
- **Evaluation System**: Two-level evaluation process with supervisor and chief approval
- **Tariff Grid Management**: Comprehensive salary and rate management system
- **Notification System**: Real-time alerts for approvals, assignments, and updates
- **Import/Export**: Excel-based data import for employees, assignments, and reports
- **Backup System**: Automated database backups with configurable scheduling

### Technical Capabilities
- Cross-platform mobile application (Android) via Capacitor
- RESTful API with authentication and authorization
- Real-time data synchronization
- Conflict detection and resolution workflows
- Audit logging and data integrity tracking

## Target Users and Use Cases

### Primary Users
1. **Project Administrators**: Manage system configuration, users, and overall project setup
2. **Department Heads**: Approve evaluations, manage assignments, and oversee team performance
3. **Economists**: Handle tariff grids, salary calculations, and economic reporting
4. **Field Workers**: Submit daily reports and view personal assignments/evaluations

### Key Use Cases
- Daily evaluation submission and approval workflow
- Employee assignment to specific construction sites and work units
- Real-time notification of pending approvals and updates
- Historical data analysis and reporting
- Multi-site coordination and resource allocation
