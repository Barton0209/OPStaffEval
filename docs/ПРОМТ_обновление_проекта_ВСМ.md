# ПРОМТ ДЛЯ ОБНОВЛЕНИЯ ПРОЕКТА
## «Система оценки компетенций работников ВСМ» — этап: разграничение прав, новая авторизация, загрузка данных, аналитика

---

## 1. КОНТЕКСТ И ОБЩАЯ ХАРАКТЕРИСТИКА ПРОЕКТА

| Параметр | Значение |
|---|---|
| Назначение | Система оценки компетенций работников ВСМ (оценка прорабами/мастерами) |
| Backend | Python 3.11+ / FastAPI / SQLAlchemy 2.0 / SQLite (WAL) / APScheduler |
| Frontend | React 19 / TypeScript / Vite / Capacitor 8 (Android APK) |
| Развёртывание | Caddy (LAN, HTTP), Windows batch-скрипты, Android APK |
| Аутентификация | JWT (HS256), Bearer token, инвалидация через token_version при смене пароля |
| Роли | admin, admin_op, master, foreman, site_chief, economist |
| БД | SQLite 3 с WAL, бэкапы через sqlite3.backup() API |

**Главный принцип обновления:** при входе в систему каждый пользователь видит и делает ТОЛЬКО свою работу — никуда дальше и больше не «лезет». Разграничение прав — жёсткое, на уровне UI и API.

## 3. ЛИЧНЫЕ КАБИНЕТЫ ПО РОЛЯМ (строгое разграничение)

### 3.1. Экономисты ОП
- Видит вкладку **«Экономисты»** (и только её).
- Загружает файл по утверждённой форме: обновлённые данные по сотрудникам — табельный номер, ФИО, должность, разряд, признак «были изменения / не были изменения» (изменения подсвечивать цветом, если требуется), тарифная ставка (мин./макс.).
- Загруженная информация транслируется (доступна) только **руководству, начальнику участка и админам**.

### 3.2. Администрация ОП (кнопка «Администрация»)
Вкладки:
1. **«Загрузить новых сотрудников»** — импорт новых сотрудников в систему.
2. **«Изменить/поменять прораба»** — смена прораба у существующих в системе сотрудников.
3. **«Уволенные»** — удаление уволенных по принципу Google-таблиц (мягкое удаление):
   - Сотрудник переносится в отдельную базу уволенных (история сохраняется: стаж, оценки, ЧТК и пр.).
   - При повторном трудоустройстве можно посмотреть всю историю по человеку.
   - База уволенных доступна для подбора персонала и выгружается в **Excel** (выгрузка всей базы уволенных).

### 3.3. Начальник участка (site_chief)
- Видит: сколько анкет «висит» (не оценено) и сколько уже оценено.
- Неоценённые анкеты: **оценок мастеров НЕ видит**.
- Оценённые анкеты: видит итоговую оценку и всю информацию по сотруднику (табельный номер, ФИО, итоговая оценка, ЧТК).
- Эту же вкладку может смотреть **Руководство ОП**.

### 3.4. Руководство ОП — «Свод» (без реестров и выгрузок!)
Отдельный сводный экран-дашборд (без фильтров «реестр», без ручных выгрузок — максимально просто):
- Пользователь нажимает, например, **«Теплоизоляция»** → видит по диапазонам оценок:
  - оценка 1–2: N сотрудников
  - оценка 2–3: N сотрудников
  - оценка 4–5: N сотрудников
- Клик по диапазону → раскрывается **список этих сотрудников** (без переходов в другие разделы).
- Кнопка «Сохранить/Выгрузить» → скачивание списка в **Excel**.
- Аналогично по каждому участку/отделу (например, «Строительные леса» и т.д.).
- На основе этого руководитель принимает решения о переводе на другие ОП и видит, кого отправить.

### 3.5. Выгрузки (серверные)
- На сервере должен выгружаться **Excel со ВСЕМИ сотрудниками** (полная информация) — рядом с блоком выгрузки.
- **Пакетная выгрузка PDF анкет**: выбор по ФИО или по фильтру (участок + должность, например: участок «Теплоизоляция», должность «изолировщик») → «Выделить всё» → «Скачать PDF» → скачиваются PDF всех выбранных анкет сразу (не по одному).

## 6. ТРЕБОВАНИЯ К РЕАЛИЗАЦИИ

1. **Простота:** всё делать предельно просто, без лишних промежуточных шагов.
2. **Разграничение прав:** на уровне и UI, и API (проверка роли на бэкенде в каждом защищённом эндпоинте).
3. **Приоритет изменений:** новая авторизация («Оценка» / «Контроль») → ролевые кабинеты → загрузка файлов по новым форматам → свод и выгрузки (Excel/PDF) → база уволенных.
4. **JWT:** сохранить текущую схему (HS256, Bearer, token_version), расширить claims ролями/площадкой/отделом.
5. **Мягкое удаление** уволенных с переносом в архивную таблицу и выгрузкой в Excel.
6. **Логирование** загрузок файлов: имя файла + дата загрузки (DD.MM.YYYY) — отображать в UI.
