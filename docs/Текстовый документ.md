1\. Основная сфера деятельности

Корпоративная автоматизация и HR: Разработка и поддержка корпоративной информационной системы (VSM OMiK) для управления персоналом в строительной компании.

Обработка больших данных: Работа с таблицами свыше 200 000 строк и 113 000 записей сотрудников (прием, перевод, увольнение, командировки).

2\. Ключевые технологии и инструменты

Excel (2016, русская версия): Написание VBA-макросов, условное форматирование (валидация: желтый/красный цвет), расчет возраста и стажа (1 год = 365 дней, 1 месяц = 30 дней), правильное склонение слов ('год', 'года', 'лет'), сохранение ведущих нулей, форматирование ФИО (Фамилия И.О.), настройка печати под вид Word, модульные макросы для отдельных листов.

Python: Скрипты для автоматизации Excel и обработки данных. Используемые библиотеки: pandas, numpy, Polars (для больших файлов), openpyxl, XlsxWriter, xlwings и другие специализированные библиотеки для работы с разными форматами (.xlsx, .xls, .xlsb).

Базы данных: SQLite (файл analytics.db), DuckDB (привязка данных к веб-таблицам).

Веб-разработка и бэкенд: FastAPI (мини-сервис excel-service), Next.js, React, Node.js, использование Bun как пакетного менеджера.

Контроль версий: Git, Git LFS (для исключения тяжелых файлов БД из основного трекинга).

3\. Критические ограничения среды

Операционная система: Windows 11.

Отсутствие прав администратора: Это ключевое ограничение. Любые решения должны работать в стандартном контексте пользователя (без доступа к C:\\Windows\\Temp, без установки системных служб или требующих повышения прав инсталляторов типа MSIX).

Инфраструктура: Отсутствие поддержки Docker.

Лицензирование: Предпочтение строго бесплатного, современного и мощного ПО.
