# Отчёт конвертации 03_Карнет (уточнение)

## Правила от заказчика

1. **Нет primary** — не ошибка: межвахта / дома, мастер или ПР появится по приезду на ОП → вносит Админ_ОП.
2. **Кандидаты** (`tab_no=Кандидат`) — ещё официально не трудоустроены, **оценивать рано**.

## Цифры

| Группа | Кол-во | evaluate |
|---|---|---|
| Всего в карнете | 908 | |
| Кандидаты | **17** | **no** (status=`Кандидат`, primary очищен) |
| Ждут назначения primary | остальные без primary | no |
| С primary | готовы к оценке | yes |

## Что сделано в файле

- У 17 кандидатов: `status=Кандидат`, `evaluate=no`, primary/secondary очищены, строки подсвечены
- Лист **`Кандидаты`** с полным списком
- Правило внесено в `docs/TZ_v0.2.md` (§4.2) и `docs/Admin_OP_i_Karnet.md`
